# Cinema icons

**English** · [العربية](README.ar.md)

The player and Like PNGs (`play`, `pause`, `rotate-ccw`, `rewind`, `fast-forward`,
`volume-2`, `volume-x`, `x`, `heart`) are rendered from the matching SVG files in
[Feather 4.29.2](https://github.com/feathericons/feather/tree/v4.29.2/icons).
They are 96×96 transparent PNGs, produced with `rsvg-convert --width 96 --height 96`;
the app applies the foreground tint. See `LICENSE-feather.txt` for the MIT license.
Existing sidebar icons and their accompanying licenses are retained.
