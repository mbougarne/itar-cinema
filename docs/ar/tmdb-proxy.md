# استخدام TMDB في إطار سينما

[فهرس الأدلة العربية](README.md) · [English](../tmdb-proxy.md)


يمكنك تجربة الكتالوج بثلاث طرق. يعرض خيار **Offline fixtures** عناوين خيالية مضمّنة ويعمل دون خادم. أمّا خيار **TMDB proxy** فيتّصل بخادم Node محلي. يمكن تشغيل الخادم في وضع المحاكاة، أو تزويده بمفتاح واجهة TMDB من الإصدار الثالث لجلب الكتالوج ونتائج البحث وتفاصيل الأفلام والممثلين وسِيَرهم.

## تشغيل مثال المتصفح مع بيانات TMDB الفعلية

استخدم Node 22.23.4 وضع مفتاحك الخاص بواجهة الإصدار الثالث في متغيّر `MOVIE_DATABASE_API_KEY` داخل الملف `.env` في جذر المستودع. يبيّن [.env.example](../../.env.example) الصيغة، ويستثني Git الملف الحقيقي. احتفظ بالقيمة الفعلية في ملف الخادم. يقرؤها الخادم عند تمكين الوضع الفعلي صراحةً.

**1. شغّل الخادم** في نافذة طرفية من جذر المستودع.

<div dir="ltr">

```sh
npm run tmdb:proxy -- --live --allow-tmdb-key-use --allow-web
```

</div>

**2. تحقّق من وضع الخادم وشغّل التطبيق** في نافذة طرفية ثانية. إذا كانت هذه المرّة الأولى، أكمل [إعداد متصفح الحاسوب](devices/web-tv.md#متصفح-الحاسوب).

<div dir="ltr">

```sh
curl http://127.0.0.1:8789/health
npm run web
```

</div>

**3. افتح الكتالوج.** انتقل إلى `http://127.0.0.1:8081` وأرسِل نموذج الدخول التجريبي واختر ملفًا شخصيًا. افتح **Settings** ثم **Content source** ثم **Catalogue** واختر **TMDB proxy**. عُد إلى **Home** لعرض الكتالوج. تؤكّد الاستجابة التي تحتوي على `"mode":"live"` وضع الخادم، ويؤكّد ظهور عنوان مع صورته نجاح طلب الكتالوج.

يرسل الخادم استعلامات قراءة إلى `api.themoviedb.org` باستخدام مفتاح الإصدار الثالث. تُرسل عبارة البحث ومعرّفات الأفلام والأشخاص في الطلبات المقابلة لها. يتلقّى المتصفح البيانات العامة ويحمّل الصور من `image.tmdb.org`. يستمع الخادم على `127.0.0.1:8789`. يسمح الخيار `--allow-web` بمصدرَي المثال `http://127.0.0.1:8081` و`http://localhost:8081` فقط. أوقفه بواسطة Ctrl+C عند الانتهاء. [شيفرة الخادم الوسيط](../../scripts/tmdb-proxy.cjs)

## تجربة الاتصال عبر HTTP دون مفتاح

<div dir="ltr">

```sh
node scripts/tmdb-proxy.cjs --allow-web
```

</div>

اختر **TMDB proxy** في التطبيق كما سبق. يعرض خادم المحاكاة بيانات وصورًا تجريبية محلية، ولا يقرأ `.env`، ويعيد `"mode":"mock"` من مسار `/health`. عند اختبار التطبيق الأصلي على المحاكي، احذف `--allow-web`. يمكن لمحاكي Android الوصول إلى منفذ الحاسوب المحلي عبر `adb -s YOUR_ADB_SERIAL reverse tcp:8789 tcp:8789` بعد تحديد معرّف الجهاز الصحيح.

## الوصول إلى الخادم من تطبيق أصلي على تلفاز فعلي

يشير عنوان الاتصال المحلي في التلفاز إلى التلفاز نفسه. على شبكة IPv4 خاصة وموثوقة، أبقِ خادم TMDB على عنوان الحاسوب المحلي وشغّل بوّابة الجهاز في عملية منفصلة. استبدل العنوان الأول بعنوان حاسوب التطوير على الشبكة الخاصة والثاني بعنوان التلفاز عليها.

<div dir="ltr">

```sh
node scripts/tmdb-device-gateway.cjs 192.168.1.10 192.168.1.20
```

</div>

تستمع البوّابة على العنوان الأول والمنفذ 8788 وتقبل الطلبات الآتية من التلفاز المحدّد، ثم تمرّر مسارات GET المسموح بها إلى الخادم المحلي. اضبط `ITAR_TMDB_PROXY_URL=http://192.168.1.10:8788` لعملية **البناء الأصلي** وأعد بناء التطبيق. القيمة المضمّنة في العميل هي عنوان البوّابة فقط. يمكن تمريرها إلى مشروع Xcode المولَّد كإعداد بناء. أعد البناء إذا تغيّر عنوان الحاسوب. تشير روابط صور المحاكاة إلى العنوان المحلي، لذلك اختر **Offline fixtures** لاختبار تلفاز يعمل كليًا ببياناته المحلية. لا تستخدم تطبيقات تلفزيونات الويب المغلّفة هذا الإعداد الخاص بالبناء الأصلي. [شيفرة البوّابة](../../scripts/tmdb-device-gateway.cjs) · [أدلّة الأجهزة](devices/README.md)

يوفّر TMDB بيانات الأفلام وصورها، ويعرض مشغّل سينما فيلمًا تجريبيًا مستقلًا له اعتمادات خاصة. راجع شروط الاستخدام وإرشادات نسبة المحتوى إلى TMDB قبل توزيع تطبيق يتّصل بالخدمة.
